## Phase 9.1: Post-Launch Polish

**Purpose**: The README links a public demo, a phone can see the wall,
the forecast names today, and demo School no longer looks like Alex.

**Goal**: The three gated sizes (1180×820, 1366×1024, 1920×1080) are
unchanged from Phase 9.

- [x] T059 [P] [US1] Step 9.1.1 — Link the public empty-environment
      demo `https://familycalendar-demo.vercel.app` under the README
      overview, at the top of the local demo steps, and in License. Say
      it has an empty environment, sample events, and no PIN. In the
      Vercel section, say the live install still needs the PIN screen,
      is separate from the public demo, and is not linked. File:
      `README.md`. — PR #1, DAS-6
- [x] T060 [P] [US2] Step 9.1.2 — Stop the scaled stage clipping
      itself. Add `.kiosk-fit` between `.kiosk-frame` and
      `.kiosk-stage`. Below 1180 wide or 820 tall, size `.kiosk-fit` to
      the painted result (`1180px` and `820px` times
      `min(100cqw / 1180px, 100cqh / 820px)`), position the stage
      absolutely at its top left, and scale with
      `transform-origin: top left`. Files: `app/page.tsx`,
      `app/globals.css`. — PR #2
- [x] T061 [US2] Step 9.1.3 — Phone rules. Portrait at most 900px wide:
      show `.kiosk-rotate-notice` ("Rotate to landscape") on
      `#0a0a0f` with safe-area padding and hide `.kiosk-frame`.
      Landscape at most 520px tall and at most 1023px wide: drop the
      transform, fill the screen, tighten the header type and padding,
      and let the day list scroll with `overscroll-behavior: contain`.
      Neither rule matches a gated size. Files: `app/page.tsx`,
      `app/globals.css`. Depends on T060. — PR #2
- [x] T062 [P] [US3] Step 9.1.4 — Label the forecast day that equals
      today in `TIMEZONE` as "Today" via `forecastDayLabel()` and
      `zonedDayKey()` built on `calendarDateParts()`. Other days keep
      `weekdayShort()`. File: `components/widgets/WeatherWidget.tsx`.
      — PR #3, DAS-21
- [x] T063 [P] [US3] Step 9.1.4 — Recolor demo School from `#8b5cf6` to
      `#eab308` in the demo calendar list and the `--color-cal-school`
      token. Files: `lib/demo-data.ts`, `app/globals.css`. — PR #3,
      DAS-22
